STEP 2: Build the project
================================================================

cd /Users/zepengli/work/StanfordReadout/no-OS/projects/ad4134_fmcz
make PLATFORM=xilinx TARGET=zed

Note: If you get errors, try:
make clean
make PLATFORM=xilinx TARGET=zed

STEP 3: Files created
================================================================

The build will create:
- build/ad4134_fmcz.elf (executable)
- build/ad4134_fmcz.elf.size (size info)

STEP 4: Program and run
================================================================

1. Program FPGA with the new bitstream (from hdl project):
   hdl/projects/ad4134_fmc/zed/.../system_top.bit

2. Load executable:
   - Via JTAG using Vitis
   - Or create BOOT.bin for SD card

3. Monitor serial output:
   - Baud rate: 115200
   - 8N1, no flow control

================================================================
QUICK FIX FOR COMMON ERRORS
================================================================

ERROR: undefined reference to 'streaming_init'
FIX: Add "SRCS += $(PROJECT)/src/ad4134_continuous_streaming.c" to src.mk

ERROR: Multiple definition of 'main'
FIX: Only include ONE main file (either streaming_example.c OR ad713x_fmc.c)

ERROR: cannot find -lxil
FIX: Ensure Xilinx BSP libraries are in path

ERROR: xil_cache.h: No such file
FIX: Export hardware from Vivado and update BSP in Vitis
